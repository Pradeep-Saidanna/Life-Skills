# Good Practices for Software Development

1. Which point(s) were new to you?  
One thing that was new for me was understanding how important communication is in software development. I learned that informing teammates early about delays, issues, or requirement changes helps the whole team work better. I also understood that asking questions properly with explanations and screenshots makes it easier for others to help.

2. Which area do you think you need to improve on? What are your ideas to make progress in that area?  
I think I need to improve my focus and communication while working on tasks. Sometimes I get distracted or spend too much time solving issues alone. To improve this, I want to avoid distractions during coding, follow a proper routine, take notes during meetings, and communicate clearly whenever I face any problem or delay.
